# RelateTime - 人物关系时间轴推算图谱 

[English](README.md) · **简体中文**

**RelateTime** 是一款专为创作者、网文写手和世界观构建者设计的 Obsidian 核心插件。它基于 React 和高性能的 D3.js 物理引擎，将沉闷的 Markdown 文本属性转化为**随时间流转的动态人物关系网**。

本插件是通过Agent创造的。

通过独创的“混合确定性引擎 + 大模型全局知识图谱补全”，RelateTime 能够自动补全你未写出的复杂亲属、同门与姻亲关系，并在出现逻辑或性别矛盾时向你发出警告。

## ✨ 核心特色 (Features)

### 🕰️ 全尺度超精度时间轴 (Ultra-Precision Timeline)
- **支持公元前 (BC/BCE)**：无论是史前时代、修真纪元还是星际未来，支持从公元前 3000 年到未来的无限跨度。
- **动态无极缩放**：支持从“年代视图（100年）”无缝平滑缩放至“小时视图（精确到具体某日某时）”。
- **状态同步流转**：拖动时间轴，图谱将实时展示该时间节点下确切生效的人物关系。

### 🧠 混合推算引擎 (Hybrid Inference Engine)
- **100% 稳定的本地规则引擎**：自动实现亲兄弟姐妹互推、同父母互推、同门师父共享等确定性逻辑，零延迟且结果绝对一致。
- **大模型全局图谱补全 (LLM Integration)**：接入兼容 OpenAI 格式的大模型 API（如 gpt-4o 或本地 LM Studio）。模型将分析全网人物，自动推算跨代（祖孙/师祖）、旁系（叔伯/姑舅）与姻亲（大嫂/岳父母/大舅哥）关系。
- **两档推算模式**：提供“展示部分推算（仅核心直系与闭环）”和“展示全部推算（含旁系跨代）”供灵活切换，避免连线爆炸。

### 🛡️ 智能伦理冲突检测 (Conflict Detection)
- 自动核验笔记中的“性别”属性与填写的“关系称谓”是否匹配。
- 当出现逻辑矛盾（如：设置性别为男，却被填写为妻子的角色；或辈分长幼发生互斥交叉）时，图谱会高亮显示**红色警示连线**，悬停即可查看详细的冲突分析浮窗 (Tooltip)。

### 🎨 优化的 D3 几何渲染 (Smart Graph Routing)
- **流式槽位防重叠排版**：多条关系连线（如两人既是夫妻又是师徒）会自动按固定间距平行展开，文字沿连线方向交错避让，彻底消灭文字重叠。
- **智能单线双向合并**：正反向相同的关系（如“朋友 ⇄ 朋友”、“同门 ⇄ 同门”）将智能折叠为单根实线的双向箭头，图谱清晰清爽。
- **深度自定义外观**：完全还原并增强了 Obsidian 原生图谱的物理力度设置（向心力、排斥力、连线长度等），并支持节点大小、线宽、各层级不透明度的像素级调节。

## 📦 安装说明 (Installation)

*(注：待上架 Obsidian 社区插件后，可在软件内直接搜索 RelateTime 安装。)*

**手动安装：**
1. 前往 GitHub 仓库的 [Releases 页面](https://github.com/你的用户名/obsidian-relatetime/releases)。
2. 下载最新版本的 `RelateTime.zip`。
3. 解压文件夹，并将其放入你的 Obsidian 仓库目录下的 `.obsidian/plugins/` 文件夹中。
4. 重启 Obsidian，在 `设置 -> 第三方插件` 中启用 **RelateTime**。

## 🚀 快速上手 (Usage)

### 1. 完善人物卡片 (Frontmatter)
在你的 Obsidian 笔记中，确保包含以下 YAML Frontmatter 属性：

```yaml
---
type: 人物
character-name: 温迪
性别: 男
关系: 张三 - 师父（2020-08-13 BC 1:00 ～ 2024-08-26 BC 17:00），李四-夫妻（2025-08-13 BC 13:00:00 ～ 2025-08-26 BC 13:00:00）、赵五 -大哥（固定）
---
```

*(注：`type` 的属性名和属性值均可在插件设置中自定义。)*

**关系：**

有可能是公元后（没有BC），也有可能没有几点几分，有的关系是不会随着时间变化的就用**（固定）**来表示。

例如，`张三 - 师父（2020-08-13 BC 1:00 ～ 2024-08-26 BC 17:00）`这个属性表明：在 2020-08-13 BC 1:00 ～ 2024-08-26 BC 17:00 ，**张三**是**本文件**的**“师父”**。

### 2. 配置大模型 (可选，用于全局深度推算)

1. 打开 RelateTime 插件设置页面。
2. 找到 **大模型 (LLM) 关系推演设置**。
3. 填入你的 API URL（支持本地模型地址）和 API Key。
4. 填入模型名称（如 `gpt-4o-mini`），点击“hi测试”校验连通性。
5. 在图谱左上角点击 **“AI 重新推演关系”** 即可一键生成全局高阶关系。

### 3. 操作图谱

- 点击左侧边栏的 **“关系网”图标** 打开视图。
- **拖拽底部刻度尺** 平移时间。
- **滚动鼠标滚轮** 放大/缩小时间轴精度。
- **点击节点** 锁定焦点，**右侧菜单** 提供强大的搜索（连带显示邻居）与外观定制功能。
